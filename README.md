# Drone Simulation System

A concurrent C++ simulation engine for autonomous drone navigation. This project implements advanced software design patterns and multi-threaded communication to manage drone flight logic, sensor data, and map exploration.

## Key Features
* **Concurrent Execution:** Multi-threaded drone logic for real-time simulation.
* **Design Patterns:** Implementation of Strategy and Factory patterns for modular command execution.
* **Network Integration:** Support for drone-to-server communication protocols.
* **Modular Architecture:** Organized folder structure with separated headers (include/) and source files (src/).

## Project Structure
* include/ - Header files (.h)
* src/ - Implementation files (.cpp)
* main.cpp - Application entry point

## How to Build
1. Open ConsoleApplication.slnx in Visual Studio 2022.
2. Set configuration to Debug or Release for x64.
3. Build Solution (Ctrl+Shift+B).
